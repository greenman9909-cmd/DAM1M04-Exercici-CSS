Proyectos

Proyectos personales

Me gusta experimentar con páginas web sencillas y herramientas de inteligencia artificial. Algunos proyectos los hago para practicar y aprender nuevas formas de crear aplicaciones.

  • Página web personal creada con HTML y CSS.
  • Pruebas de prompts para obtener mejores respuestas de herramientas de IA.
  • Ideas de pequeñas aplicaciones creadas con ayuda de inteligencia artificial.

Pasos para crear un proyecto

  1. Pensar una idea o necesidad.
  2. Preparar la estructura del proyecto.
  3. Utilizar HTML y herramientas de IA para desarrollarlo.
  4. Probar el resultado y corregir errores.
  5. Publicarlo en GitHub.
